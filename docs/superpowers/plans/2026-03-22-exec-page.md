# Exec Page & Terminal Session Management

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a full-page exec terminal with multi-tab sessions (like the logs page), add a status bar terminals popover for quick session access, and make the floating terminal panel user-controlled (only shown when explicitly requested).

**Architecture:** The exec page (`/exec` route) is the "full view" of terminal sessions from `TerminalContext`. It shares sessions with the existing floating `TerminalPanel` — both read from the same context. The floating panel is hidden on `/exec` and only shown on other pages when the user explicitly clicks a session in the status bar popover. A new `TerminalPopover` component in the status bar lists active sessions with click-to-switch. A container picker dialog (like the logs `StreamPickerDialog`) lets users start new exec sessions from the exec page.

**Tech Stack:** React, TanStack Router, ghostty-web (terminal emulator), WebSocket, Tailwind CSS v4, Lucide icons

**Design reference:** `docs/design.pen` — screen `f8D6u` (Exec)

**Key behaviors:**
- Exec page shows tabs + full terminal views (same pattern as logs page)
- Sessions persist across pages via `TerminalContext` (already works)
- Floating `TerminalPanel` is NEVER auto-shown. Only shown when user clicks a session in the status bar popover while NOT on `/exec`
- On `/exec` page, floating panel is hidden (full page view takes over)
- Status bar terminals segment is clickable → opens popover with session list
- "+" button on exec page opens a container picker dialog

### Task 4: Hide Floating Panel on /exec Route

**Files:**
- Modify: `app/src/components/terminal-panel.tsx`

The floating panel should not render when the user is on the `/exec` route (the full page view handles terminals there).

- [ ] **Step 1: Add route check**

Use `useMatches()` from TanStack Router to detect the current route. If the last match's path starts with `/exec`, return `null` (don't render).

```tsx
import { useMatches } from "@tanstack/react-router";

export function TerminalPanel() {
    const matches = useMatches();
    const currentPath = matches[matches.length - 1]?.fullPath ?? "/";

    // Don't show floating panel on the exec page — it has its own full view
    if (currentPath.includes("/exec")) return null;

    // ... rest of component
}
```
